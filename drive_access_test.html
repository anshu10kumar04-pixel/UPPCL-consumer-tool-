Google Cloud Console mein Client ID banane ka tarika (ek baar ka kaam, ~5 minute)

  1. console.cloud.google.com kholo (apne kisi bhi Google account se, personal Gmail bhi chalega).
  2. Upar-left "Select a project" → "New Project" → naam do "UPPCL Tool Test" → Create.
  3. Left menu → "APIs & Services" → "Library" → search "Google Drive API" → Enable.
  4. Left menu → "APIs & Services" → "OAuth consent screen" → User Type "External" → Create → App name/email bhar ke Save (test mode mein hi rehne do).
  5. Left menu → "APIs & Services" → "Credentials" → "Create Credentials" → "OAuth client ID" → Application type "Web application".
  6. "Authorized JavaScript origins" mein add karo: jahan se ye HTML file khola jayega us origin ko (agar sirf apne computer par file double-click karke khol rahe ho to http://localhost nahi chalega — is file ko kisi simple hosting jaise GitHub Pages par daal ke uska URL yahan daalna behtar rahega, jaise https://anshu10kumar04-pixel.github.io).
  7. Create dabane ke baad jo Client ID milega (xxxx.apps.googleusercontent.com jaisa dikhega), usko upar Step 1 wale box mein paste kar do.
